# WTV 地图 UI 样式改动总结（2026-07-22）

> 范围：`wpo-app/libs/wpe/src/lib/features/well-test-validation-overview/`
> 涉及组件：`map-panel`、`map-filter-panel`；对应需求 REQ-20260722 / REQ-20260722b。

## 1. Legend「With / Without Actions」说明弹窗

- Legend 两个标记的文案由 `Exeptions` 更正为 **Actions**：`Well Without Actions` / `Well With Actions`。
- 每行新增 **info (i)** 按钮，点击弹出说明面板，改用 PrimeNG **`p-popover`** 实现。
- 面板内容按状态域分组展示「哪些状态属于 with / without action」，由 `ALERT_STATUS_BY_GROUP`（逻辑）+ `STATUS_SEMANTIC_CONFIG` + `WTV_STATUS_PALETTE`（颜色）驱动，单一数据源。

### 设计规格（弹窗内容）
| 元素 | 规格 |
|---|---|
| 顶部标题（Well With/Without Actions） | 字号 **14px**，字重 **600（加粗）** |
| 四个类型标题（分组标题） | 字号 **14px**，字重 **400（不加粗）** |
| 状态文字 | 字号 **14px**，字重 **400** |
| 颜色色块 `swatch` | 宽 **16px** × 高 **8px**，圆角 2px |
| 每个状态行 | `min-height: 25px`，色块与文字 `gap: 8px` |
| info 图标 | 使用 `info.svg`（内联，**20px**，`fill=currentColor`：浅色 `#141d27` / 暗色 `#b7c4d1`），去掉圆圈边框；**鼠标悬停无颜色变化** |
| 弹窗内容 | **不出现滚动条**（随内容自适应高度，无 `max-height`/`overflow`） |

### 弹窗容器（`.map-legend-popover.p-popover`）
- `border-radius: 4px` + `border: 1px solid var(--p-popover-border-color)`。
- `box-shadow: 0 8px 24px rgba(18,30,44,.18)`。
- 箭头所在角取消圆角：上翻（`.p-popover-flipped`）去 `border-bottom-right-radius`，下翻去 `border-top-right-radius`。
- **暗色主题字色**：`p-popover` 内容被挂到 `<body>`，`:host-context()` 不生效，故用全局 `[data-theme='dark'] .map-legend-popover` 补字色（标题 `#e2e8f0` / 类型 `#9fb0c0` / 状态 `#d5deea` / 分隔线 `#223141`）。

### 弹窗箭头
- PrimeNG 默认箭头对「贴地图右边缘的小目标」定位会偏移，改为**自定义箭头**：
  - 隐藏默认 `:before/:after`；
  - 用旋转 45° 的方块「缺口」，颜色/边框取 `--p-popover-background` / `--p-popover-border-color`（自适应主题）；
  - 锚定 **`right: 6px`**，对准右下角 (i) 按钮；
  - 方向自适应：弹窗在上方（`.p-popover-flipped`）→ 缺口朝下；在下方 → 朝上。

### 抽离为可复用组件 `com-legend-popover`
- 上述 (i) 按钮 + `p-popover` + 分组色块内容 + 自定义箭头/边框/阴影/暗色适配，已抽离为独立组件 **`com-legend-popover`**（选择器 `com-legend-popover`）。
- 位置：`libs/wpe/.../well-test-validation-overview/shared/com-legend-popover/`（WTV 功能内的 `shared/` 下，供本功能复用）。
- 输入（signal input）：`title: string`、`groups: LegendPopoverGroup[]`（`{ title, items: { label, color }[] }`）、`ariaLabel: string`。
- 用法：`<com-legend-popover [title]="'Well With Actions:'" [groups]="withActionGroups"></com-legend-popover>`。
- `map-panel` 通过相对路径 `../../shared/com-legend-popover/com-legend-popover.component` 引用；相关样式/模板已从 `map-panel` 移除。

## 2. 井侧边过滤面板「Map Display Control」

> ⚠️ **部分已被取代（2026-07-23）**：本节的「可展开树 + 状态子级 + 展开状态持久化」结构
> 已精简为**分类级复选框**；侧栏职责由「过滤井」改为「决定图标颜色」。见
> [2026-07-23-wtv-map-filter-color.md](2026-07-23-wtv-map-filter-color.md)。以下保留作历史记录。

### 抽离为可复用外壳组件 `com-map-filter-sidebar`（`libs/shared`）
- 侧边栏**外壳**（开关按钮 + 面板 chrome + 标题 + Reset/Apply）抽离为通用组件 **`com-map-filter-sidebar`**（选择器同名，位于 `libs/shared/src/lib/components/com-map-filter-sidebar/`），供其他 map 功能复用。
- **内容用 `ng-content` 投影**：具体过滤控件由调用方放入；外壳只负责开关、chrome、Reset/Apply。
- 输入：`title`（默认 `Map Display Control`）、`applyDisabled`。输出：`apply`、`reset`、`openChange`。方法：`open()/close()/toggle()`、`overlayElements()`（供宿主在全屏时迁移）。
- Apply/Reset 会**先 emit 再自动关闭**面板。
- WTV 用法：
  ```html
  <com-map-filter-sidebar title="Map Display Control"
    (apply)="onSidebarApply()" (reset)="onSidebarReset()" (openChange)="onFilterSidebarOpenChange()">
    <wtv-map-filter-panel [initialEnabledDomains]="appliedDomains()" [initialExpandedDomains]="expandedDomains()"
      (expandedChange)="onFilterExpandedChange($event)"></wtv-map-filter-panel>
  </com-map-filter-sidebar>
  ```
- `map-panel` 通过 `@ViewChild` 读取投影内容的选择：Apply → `filterContent.getSelectedDomains()`；Reset → `filterContent.resetSelection()`。

### 投影内容 `wtv-map-filter-panel`（WTV 专属树）
- 内容参考 V1 `wfc-gis-side`：四个状态域（Well Test Validation Status / Well Test Priority / Model Calibration Status / Well Model KPI）。
- 每个分类为一行：**展开箭头 + 复选框 + 分类标题**；展开后子级状态为**纯标签**（无复选框）。
- 只保留树本身；header 与 Reset/Apply 已上移到外壳组件。对外暴露 `getSelectedDomains()` / `resetSelection()`，输出 `expandedChange`。

### 开关按钮（参考 WIM map-host，位于外壳组件内）
- PrimeNG `pButton`，`icon="fas fa-layer-group"`，`class="map-filter-sidebar__toggle p-button-secondary"`。
- `pTooltip: Show Filter`；位置：地图右缘**垂直居中**；面板打开时隐藏（关闭由 Apply/Reset 触发）。
- 标题图标与开关按钮图标**统一**为同一 `fas fa-layer-group`。

### 行为
- **Apply**：发出启用的状态域 → 过滤地图 → 自动关闭面板。
- **Reset**：全选 → 恢复全部显示 → 自动关闭面板。
- **状态持久化**：勾选状态与展开/折叠状态提升到父组件保存，重开后还原（不再每次重置为全选、全展开）。
- **默认**：四个分类**全部折叠**。

### 尺寸 / 布局
- 面板高度**自适应**：`top: 16px; bottom: 130px`（底部预留空间，不遮挡右下角 legend）；顶部间距与顶部按钮一致。
- 全屏：`:fullscreen` 下 `top: 16px; height: calc(100% - 32px)`（上下留边）——注：后续统一改为 top/bottom 锚定后两种模式一致。
- 内容区 `.mdc__body`：`flex: 0 1 auto; min-height: 0; overflow-y: auto`——内容少时按钮紧随内容，内容多时列表滚动、Reset/Apply 固定可见（header/actions `flex: 0 0 auto`）。
- Reset / Apply：`justify-content: space-between`，左右 `padding: 16px 18px 0`（两侧 18px）。
- 过滤面板与切换按钮已接入**全屏 overlay 宿主迁移**，全屏下同样可用。
