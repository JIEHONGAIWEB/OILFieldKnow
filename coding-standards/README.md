# coding-standards

Language/framework-agnostic coding standards for this project: naming, formatting, error handling, logging conventions.

## Standards

- [frontend-angular-primeng.md](frontend-angular-primeng.md) — **mandatory**
  Angular + PrimeNG standard for all `*.ts` / `*.html` / `*.scss` frontend
  code. Every frontend change (human or AI) MUST comply.
  - §8 Code Organization:复杂功能按职责分组、全中文注释、导出顺序整理。
- [frontend-angular-primeng-zh.md](frontend-angular-primeng-zh.md) — 上述规范的
  **中文版**(以英文版为准,两者需保持同步)。
