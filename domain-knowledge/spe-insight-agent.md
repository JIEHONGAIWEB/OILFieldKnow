# SPE Insight Agent(DS365.ai)

> 来源:Landmark 内部帖子,作者 Youli Mao(帖子显示 "7h ago",42 人已读)
> 标题原文:*Introducing the SPE Insight Agent in DS365.ai: Bringing Decades of Petroleum Engineering Knowledge to AI*

## 一句话概述

Halliburton 获得 SPE(石油工程师学会)技术内容的数据授权,并基于 12.4 万+ 篇 SPE 论文构建了 AI 就绪的知识库,在 DS365.ai 中推出 **SPE Insight Agent**。

## 背景:数据授权协议

- Halliburton 与 SPE 达成新的**数据授权协议**。
- 协议允许 Halliburton 使用 **OnePetro 语料库**中的 SPE 技术内容。
- 用途:
  - 开发先进的 AI 解决方案
  - 技术智能(technical intelligence)
  - 面向能源行业客户的应用

## 已完成的工作

| 项目 | 说明 |
|------|------|
| 知识库规模 | 124,000+ 篇 SPE 技术论文 |
| 覆盖范围 | 13 个学科领域 |
| 形态 | 全面的、AI 就绪(AI-ready)的知识库 |
| 上层产品 | SPE Insight Agent(构建于该知识库之上) |

## SPE Insight Agent 能做什么

通过**自然语言、上下文感知的对话**,用户可以:

1. 提出技术问题
2. 跨相关 SPE 知识综合洞见(synthesize insights)
3. 探索工程方法与方案
4. 将 **SPE 知识**与**客户授权数据**结合,支持技术决策

> **在 DS365.ai 中推出 SPE Insight Agent:将数十年的石油工程知识带入 AI**
