# Oilfield Domain Glossary

石油领域术语表。

| Term (EN) | 术语 (中) | Definition |
|---|---|---|
| Well Surveillance | 油井监控 | Monitoring well & equipment health over time. |
| Well Test | 试井 / 产量测试 | A measurement of a well's flow rates over a period. |
| Well Test Period | 试井周期 | Time span associated with a well test measurement. |
| Run Life | 运行寿命 | How long downhole equipment (e.g. ESP) runs before failure. |
| Survival Analysis | 生存分析 | Statistical failure/hazard modelling (incl. Weibull). |
| Hazard Curve | 风险曲线 | Instantaneous failure rate over time. |
| Flow Rate | 流量 / 产量 | Volume of fluid produced per unit time. |
| Model Quality | 模型质量 | Rating of a well's production model accuracy. |
