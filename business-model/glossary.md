# Glossary

| Term | Definition |
|---|---|
| WPO | Well Performance Optimization — the product name / production-optimization feature. |
| WPE | Well Performance Evaluation — evaluates well performance (`/wpe`, `WpeModule`). |
| WSO | Well Surveillance Optimization — surveillance optimization workflows (`/wso`, `WsoModule`). |
| RLA | Run Life Analysis — equipment run-life analytics (`rla`). |
| WTV / WTE | Well Test Validation / Well Test Evaluation. |
| PDM | Petroleum Data Management — the backend data platform accessed via BO queries. |
| BO | Business Object — a named PDM entity (e.g. `WELL_TEST`) queried via `BOQuery`. |
| BOQuery | Structured query object (selectList, criteriaFilters, joins) sent to PDM. |
| SDH | Surveillance Data Hub — source of the `SDHFilter` NgRx state. |
| MFE | Micro-frontend — this app is a Module Federation remote. |
| AERL | Average Estimated Run Life (run-life KPI). |
| Model Quality | Well model rating: Good / Moderate / Bad / Wells without Model. |
